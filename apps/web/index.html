Sanfran.md – Skills jurídicas para agentes de IA

Sanfran.md é uma plataforma e catálogo de skills jurídicas brasileiras para agentes de IA via MCP (Model Context Protocol). Sanfran.md é o manual jurídico brasileiro do seu assistente de IA. Conecte o contexto jurídico brasileiro diretamente ao seu assistente (Claude, Grok, GPT..) via MCP. Reduza as alucinações e crie fluxos de trabalho seguros. Use centenas de skills com um plug. Oferecemos infraestrutura pronta para o seu dia-a-dia jurídico com foco em privacidade. Suas skills privadas nunca vão para a internet. Nossa arquitetura garante isolamento total: apenas o seu escritório acessa o conhecimento criado pelo seu time. Oferecemos atualização em tempo real para editar ou criar novas habilidades, que são refletidas no assistente instantaneamente. Com descoberta via Embeddings, a plataforma entende o contexto do seu caso e sugere a melhor habilidade automaticamente. Catálogo inclui: CLT, LGPD, CDC, direito trabalhista, consumidor, societário e muito mais.
