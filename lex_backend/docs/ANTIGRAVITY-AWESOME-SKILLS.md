# Antigravity Awesome Skills

O diretório ``Desktop/sanfran/antigravity-awesome-skills`` contém meta‑skills que podem ser usadas como base para a fase de entrevista do Lex.  

Alguns arquivos úteis:
- ``meta-skill.md`` – define o fluxo de perguntas estruturadas (papel, normas, entrega, limites).
- ``templates/`` – contém snippets de SKILL.md que podem ser inseridos no rascunho.
- ``examples/`` – exemplos de skills já prontas para áreas do direito (CDC, CLT, etc.).

**Próximo passo:**  
1. Copiar o conteúdo relevante (por exemplo o ``meta‑skill.md``) para o nó ``01_intake`` no grafo.  
2. Adaptar o prompt do LLM no ``intake`` para referenciar esses arquivos.

Os arquivos ainda não são parte do repositório ``lex_backend``; basta importá-los via caminho absoluto quando for necessário.
