# Política de Privacidade

Esta política descreve como coletamos, usamos, armazenamos e protegemos as informações dos usuários da plataforma **sanfran.sh**.

## 1. Dados Coletados
- **Informações de Registro**: nome, email (necessário para criar conta).
- **Cookies**: para analytics e funcionalidades essenciais.
- **Logs de Acesso**: IP (anonimizado), timestamp, user‑agent.
- **Integrações de Terceiros**: tokens OAuth (ex.: GitHub, Google).

## 2. Uso dos Dados
- Autenticação e gerenciamento de conta.
- Personalização de UI (quando consentido).
- Análise de uso agregada (com anonimização).

## 3. Compartilhamento
Não vendemos ou compartilhamos dados pessoais com terceiros, exceto quando necessário para integração de login (ex.: GitHub) e apenas com o consentimento do usuário.

## 4. Retenção
- Dados de conta: enquanto o usuário mantiver a conta ou solicitar exclusão.
- Logs de acesso: retenção de 30 dias, depois excluídos.
- Cookies: conforme a escolha do usuário no banner de consentimento.

## 5. Segurança
- Todas as comunicações usam **HTTPS/TLS 1.3**.
- Dados sensíveis armazenados criptografados (AES‑256‑GCM).
- Acesso a endpoints controlado via **RBAC**.

## 6. Direitos do Usuário
- **Acesso**: solicitar cópia dos seus dados.
- **Correção**: atualizar informações de perfil.
- **Exclusão**: solicitar remoção completa da conta (`/account/delete`).

## 7. Contato
Para dúvidas ou reclamações, envie email para `privacy@sanfran.sh`.

*Esta política será revisada periodicamente para garantir conformidade com LGPD e GDPR.*
